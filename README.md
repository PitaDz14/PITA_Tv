# PITA TV

موقع لمشاهدة القنوات التلفزيونية المباشرة.

يضم الموقع مجموعة من القنوات العربية والرياضية والإخبارية والإسلامية والوثائقية
وقنوات الأطفال، مرتّبة في أقسام يسهل التنقّل بينها. تعمل القنوات داخل صفحة المشاهدة
مباشرة، مع تحديث تلقائي للبث حتى تستمر المشاهدة دون انقطاع.

## الاستخدام

افتح `index.html` في المتصفح، ثم اختر القسم الذي تريده واضغط على أي قناة لتبدأ المشاهدة.
يمكن أيضًا تثبيت الموقع على الهاتف كتطبيق.

## الأقسام

- بث مباشر للمباريات
- القنوات العامة
- قنوات الأخبار
- قنوات الرياضة
- قنوات إسلامية
- قنوات وثائقية
- قنوات الأطفال
